# Lambot 扫地机协议解码与逆向资料

> 岚豹（Lambot / Slamtec）扫地机本地 MQTT 协议的逆向与解码成果整理。非官方项目，与厂商无关。
> 本项目只收录**协议与解码方法**，不含任何真实设备凭据、内网拓扑或个人家庭信息。

## 内容

| 文件 | 说明 |
|---|---|
| `PROTOCOL.md` | 本地 MQTT 协议全表：上下行 f-code、坐标系、状态枚举、地图格式、清扫模式码（含 2026-11-19 真机更正） |
| `REA_逆向分析报告.md` | 官方 App 静态逆向分析报告（云端 REST 接口 + MQTT 命令枚举还原） |
| `API_参考.md` | 云端 REST API 接口参考 |
| `MQTT_协议参考.md` | MQTT 主题、参数键与控制命令参考 |
| `map_utils.py` | 实时 SLAM 地图 RLE 解码器：base64 → 自适应转义 RLE → PNG 位图 |

## 关键结论

- 设备自身即 MQTT Broker（默认端口 19883），纯本地直连，品牌云失效后仍可用。
- 地图数据为 base64 编码的自适应转义 RLE 位图，解码器见 `map_utils.py`。
- 控制命令需先发握手帧再下发真实命令，且部分命令之间有最小间隔要求，详见 `PROTOCOL.md`。
- 清扫模式码经真机验证：`p=1` 单遍之字（弓形）、`p=2` 井字形、`p=0` 沿边。早期抓包对 `p=2` 的标注有误，已更正。
