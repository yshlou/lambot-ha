# Lambot 岚豹扫地机 Home Assistant 集成

> 通过**本地 MQTT 协议**直连岚豹（Lambot）扫地机，无需品牌云服务。适用于品牌云已关闭、官方 App 无法使用的设备。
>
> **⚠️ 非官方项目**：本集成为逆向工程的产物，与岚豹/思岚科技无任何关联，不提供任何形式的保证。

## 功能特性

- ✅ **状态监控**：设备状态、电量、清扫面积、清扫时长、拖地模式、区域数量
- ✅ **本地控制**：开始清扫 / 暂停 / 回充（机身按键之外的第二个选择）
- ✅ **SLAM 地图**：实时解码扫地机地图为图像实体，可在仪表盘显示
- ✅ **完全本地**：设备自身即是 MQTT Broker（端口 19883），数据不出局域网
- ✅ **云无关**：品牌云（lambot.ai / slamtec.com）失效后依然可用

## 工作原理

扫地机内置一个 MQTT Broker（TCP 19883，明文），App 通过局域网直连它进行通信。
本集成扮演同样的客户端角色：

```
HA 集成  ──MQTT(19883)──>  扫地机（内置 Broker）
  ▲                              │
  └──────── 订阅 device/{id}/app ◄┘
```

### 协议要点（供排查/二次开发）

- 认证：用户名 `Lambot` / 密码 `lambot123`（从官方 App 抓包提取的出厂默认凭据）
- Topic：
  - `device/{device_id}/app`（设备上报）
  - `device/{device_id}/robot`（下发指令）
- 消息格式：`{"f": <功能码>, "p": <参数>}`

常用功能码：

| 功能码 | 含义 | 方向 |
|--------|------|------|
| f88 | 握手（控制前必须先握手） | 下发 |
| f40 | 状态查询（姿态/动作/电量/时长/面积/地图） | 下发 |
| f16 | 状态码（1 待机/充电、6 清扫中、7 暂停等） | 上报 |
| f3 | 电量 | 上报 |
| f20 | 清扫面积 | 上报 |
| f22 | 清扫时长（秒） | 上报 |
| f1 | 姿态 pose（x/y/yaw） | 上报 |
| f7 / f17 / f66 | SLAM 地图（base64，RLE 压缩位图） | 上报 |
| f26 | **开始清扫** | 控制 |
| f24 | 暂停 | 控制 |
| f25 | 回充 | 控制 |
| f53 | 轨迹查询 | 查询 |
| f42 | 房间/区域列表 | 查询 |

地图格式：`map_data` base64 解码后为 RLE 位图，魔数 `"RLE"`，从偏移 3 开始解码；
像素值 1=空闲（白）、0=未知（深灰）、高值=障碍（黑）。

> **注意**：f26 是控制指令而非查询，严禁放入轮询，否则会每周期触发一次清扫（v3.2 已修复同类问题）。

## 安装

### 方式一：HACS（推荐）

1. HACS → 右上角 → Custom repositories
2. 仓库地址：`https://github.com/yshlou/lambot-ha`
3. 类别选择：**Integration** → 添加
4. 搜索 "Lambot" 安装，重启 HA

### 方式二：手动

将 `custom_components/lambot/` 复制到 HA 的 `config/custom_components/lambot/`，重启 HA。

## 配置

HA → 设置 → 设备与服务 → 添加集成 → 搜索 **Lambot**：

| 字段 | 说明 |
|------|------|
| 主机 Host | 扫地机局域网 IP（如 192.168.1.100） |
| 端口 Port | 默认 `19883` |
| 用户名 | 默认 `Lambot` |
| 密码 | 默认 `lambot123` |
| 设备 ID | 设备的唯一 ID（见下） |

**如何获取 device_id**：抓包 App 连接 MQTT 的 CONNECT 包，或观察 `device/{id}/app` topic 前缀。
（topic 形如 `device/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx/app`，中间那段 UUID 即为 device_id）

## 兼容性

- **HA 版本**：需要支持 `probatio` 校验库的较新版本（2026.x+，Python 3.12+）
- **设备**：岚豹（Lambot）基于思岚 RoboHome 框架的扫地机（品牌云已死或不可用的同款设备）
